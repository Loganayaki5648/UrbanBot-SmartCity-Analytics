UrbanBot Intelligence – Smart City Analytics Platform

Project Overview

UrbanBot Intelligence is an AI-powered Smart City Analytics Platform that helps analyze and monitor urban conditions using Machine Learning, Deep Learning, Computer Vision, NLP, and RAG-based AI.

Key Features

- Traffic Congestion Prediction
- Accident Detection
- Streetlight Detection
- Air Quality Prediction
- Crowd Density Analysis
- Citizen Complaint Classification
- Smart Alerts
- RAG-based AI Chatbot
- Interactive Streamlit Dashboard

Technologies Used

- Python
- Machine Learning
- TensorFlow / Keras
- OpenCV
- YOLO
- NLP
- FAISS
- Streamlit
- AWS EC2, S3, RDS
- GitHub

Machine Learning Models

- Traffic: Random Forest
- Air Quality: Random Forest
- Citizen Complaints: Logistic Regression
- Accident: Random Forest
- Crowd Density: CNN
- Streetlight Detection: YOLO / Computer Vision

Cloud Deployment

The application is deployed on AWS EC2 using Streamlit.

AWS services used:

- EC2
- S3
- RDS

Run the Project

pip install -r requirements.txt
streamlit run main.py

Project Workflow

Data → Preprocessing → ML/DL Models → Prediction
→ RAG Chatbot → Smart Alerts → Streamlit Dashboard
→ AWS Deployment
